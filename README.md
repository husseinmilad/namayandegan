# سامانه جامع مدیریت و داشبورد گزارش حضور نمایندگان هیئت امنا (`namayandegan`)

اپلیکیشن تحت وب، لوکال و راست‌به‌چپ (RTL) با **فونت وزیر (`Vazirmatn FD`)** و **تقویم کاملاً شمسی** جهت ثبت جلسات کارگروه‌های تخصصی، محاسبه دقیق ساعات حضور به تفکیک هر نماینده و هر عضو هیئت امنا، ذخیره و بازیابی فایلی و صدور خروجی‌های رسمی PDF و اکسل.

## قابلیت‌های کلیدی

- **کارگروه‌های تخصصی چهارگانه پیش‌فرض:**
  1. `حسابرسی و بودجه`
  2. `اقتصاد و سرمایه‌گذاری`
  3. `بیمه و محاسبات اکچوئری`
  4. `بهداشت و درمان`
- **مدیریت ساختار هیئت امنا و نمایندگان:** تعریف و ویرایش اعضای محترم هیئت امنا، اسامی نمایندگان کارگروه‌ها و نگاشت دقیق اینکه هر فرد نماینده کدام عضو هیئت امناست.
- **ثبت جلسات با تقویم کاملاً شمسی:** ورود تاریخ جلسه (با تقویم تعاملی شمسی)، ساعت شروع و پایان جلسه، محاسبه خودکار مدت جلسه، نام کارگروه، موضوع گزارش، خلاصه مصوبات و ثبت حضور کامل یا حضور ساعتی (تأخیر/تعجیل) برای هر نماینده.
- **گزارش‌گیری تفکیکی دقیق:**
  - تعداد جلسات و میزان ساعت حضور به تفکیک **هر نماینده کارگروه** (همراه با کارنامه ریز جلسات هر فرد)
  - تعداد جلسات و مجموع ساعت حضور نمایندگان به تفکیک **هر عضو هیئت امنا** و ماتریس پوشش ۴ کارگروه
- **داشبورد مدیریتی گرافیکی با قابلیت اشتراک‌گذاری:**
  - شاخص‌های کلان (KPI)، نمودار دونات سهم کارگروه‌ها، نمودار مقایسه‌ای اعضای هیئت امنا و نمای تقویم ماهانه شمسی جلسات
  - اشتراک‌گذاری از طریق **لینک هوشمند بدون نیاز به سرور**، کپی متن رسمی مدیریتی و دانلود تصویر گرافیکی داشبورد (`PNG`)
- **صدور خروجی PDF و اکسل (`.xlsx`):**
  - گزارش چندصفحه‌ای استاندارد `A4` فارسی با فونت وزیر (`PDF`)
  - فایل اکسل ۵ برگی راست‌به‌چپ (`خلاصه کارگروه‌ها`، `اعضای هیئت امنا`، `نمایندگان کارگروه‌ها`، `فهرست جلسات و موضوعات`، `ریز حضور نمایندگان`)
- **ذخیره فایلی و بازیابی فایلی ۱۰۰٪ لوکال:**
  - ذخیره و دانلود مستقیم کل پایگاه‌داده در قالب فایل استاندارد `.json` و بازیابی (جایگزینی کامل یا ادغام هوشمند)
  - همگام‌سازی خودکار روی دیسک محلی (`data/local-db.json`) و آرشیو نسخه‌های پشتیبان در پوشه `backups/` هنگام اجرای محلی

## راه‌اندازی و اجرای لوکال

```bash
# نصب وابستگی‌ها
npm install

# اجرای محیط توسعه لوکال (http://localhost:5173)
npm run dev

# ساخت نسخه نهایی و اجرای سرور لوکال مستقل (http://localhost:4173)
npm run build
npm start
```
